# 翻译说明

```
assets/i18n/
├── zh/                 简体中文
│   ├── common.json     通用按钮、底部导航、分页器
│   ├── settings.json   设置页：外观、阅读、存储、版本探测、主题配色名
│   ├── account.json    登录 / 注册 / 个人页 / 个人资料编辑
│   ├── proxy.json      网络链路与代理设置
│   ├── comments.json   评论、轻小说评论、章节吐槽
│   ├── downloads.json  离线下载、保存到相册
│   └── browse.json     首页 / 榜单 / 搜索 / 书架 / 各类错误提示
└── en/                 英文
```

## 占位符

```json
{
    "cacheSizeLabel": "当前占用 {size}",
    "pageOf": "第 {page} / {pages} 页"
}
```

- `{size}`、`{page}`、`{pages}` 会被替换成实际数字，花括号和里面的名字都不能翻译、不能删、不能改大小写。
- 位置可以按目标语言的语序挪动：`"{size} used"` 改成 `"已用 {size}"` 都行，替换是按名字匹配的，不是按顺序。
- 如果中文有 `{n}` 而译文里丢了，界面会少一个数字，下面的校验会直接报出来。

## 带 `.one` / `.other` 的是单复数

```json
{
    "commentReplyCount.one": "1 reply",
    "commentReplyCount.other": "{n} replies"
}
```

- 英语等语言需要区分 1 条和多条：`one` 用在数量为 1 时，`other` 用在其他数量。
- 中文不区分单复数，两行写一样即可（如 `"{n} 条回复"`）。
- 两条都必须存在，`other` 里必须保留 `{n}`；`one` 里可以把数字直接写成 1（英文的 `"1 reply"` 就是这种写法）。
- 不要新增源语言里没有的占位符，否则会被校验拦下。

## 验证

```bash
flutter test test/foundation/i18n_catalog_test.dart
```

它会核对每种语言的 key 是否齐全、有没有空文案、占位符是否对得上。

## 新增一种语言

1. 复制 `en/` 整个目录，改名为语言代码（例如 `ja/`）。
2. 把每个值翻译成目标语言；文件名不要改，key 不要删，值不要留空。

## 不允许的做法

- 改 key，页面会变成直接显示代号。
- 用 `#` 或 `//` 写注释，JSON 不支持注释。
- 把英文直引号换成中文引号，JSON 只认英文直引号。
- 值里出现英文双引号，需要引号时用中文引号「」或弯引号。
- 删除整条 key，该语言会默认回退到英语显示。
